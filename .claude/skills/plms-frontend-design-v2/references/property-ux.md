# Property UX

## Discovery
Users should understand:
- where the property is
- what it is
- how much it costs
- its most important specs
- what to do next

## Card priority
Image > Price > Title > Location > Key Specs > Trust > CTA

## Property detail
Hero → price/title → specs → story → features → gallery → agent → inquiry/survey → related

## Conversion
The user should always know the next meaningful action:
- Search
- View details
- Save
- Contact agent
- Schedule survey

## Trust
Useful trust signals:
- verified agent
- clear property status
- meaningful location
- professional photography
- structured details
- concise agent profile

Do not manufacture trust badges that have no real backend meaning.
