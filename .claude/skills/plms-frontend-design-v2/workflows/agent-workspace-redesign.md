# Agent Workspace Redesign

1. Identify the top three tasks the agent needs today.
2. Put Action Needed first.
3. Reduce equal-weight metric cards.
4. Group property work separately from CRM work.
5. Use compact but breathable data presentation.
6. Convert dense mobile tables into cards.
7. Preserve existing permissions and data rules.
8. Make destructive actions secondary.
9. Keep internal workspace more structured than public marketplace.
10. Use motion sparingly; productivity wins over decoration.
