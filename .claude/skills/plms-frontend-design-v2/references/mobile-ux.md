# Mobile UX

## Principles
Mobile is a dedicated composition, not a squeezed desktop.

### Recommended
- one primary action per section
- large media
- readable price
- compact metadata row
- quick filter chips
- advanced filters in sheet/drawer
- sticky CTA on property detail when useful
- bottom nav for high-frequency destinations

### Do not
- horizontal data tables for public listings
- tiny buttons
- 5+ simultaneous filters on-screen
- dense metadata blocks
- sticky UI that covers content
- long forms without step structure

## Baseline widths
Validate at:
320, 375, 390, 430, 768, 1024, 1280+.
