# Motion

Motion communicates quality when it is restrained.

## Use
- hero reveal
- section reveal
- image micro-zoom
- card hover
- filter transitions
- modal/sheet transitions
- CTA entrance

## Timing
- 120–180ms micro
- 180–320ms components
- 320–600ms sections
- 600–1000ms ambient hero

Always support reduced motion.

Avoid continuous heavy parallax and decorative movement that competes with property imagery.
