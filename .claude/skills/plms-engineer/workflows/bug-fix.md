# Bug Fix Workflow

1. Capture the exact symptom and affected path.
2. Read the relevant route, component, hook, service, and data-access layers.
3. Reproduce or establish the failure mechanism.
4. Identify the root cause.
5. Make the smallest correct fix.
6. Add or update regression coverage when practical.
7. Run targeted validation, then broader validation as appropriate.
8. Check adjacent code for the same failure class.
9. Report root cause, fix, and evidence.
