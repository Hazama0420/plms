# INLAND Brand & Design System

## Brand Anchor
INLAND Emerald is mandatory. It is the primary brand signal.

Use emerald for:
- primary CTA
- active navigation
- important highlights
- selected controls
- brand marks
- conversion points

Use neutrals for most surfaces.

## Recommended palette relationship
- Emerald: brand
- Warm Ivory: premium light canvas
- White: content surface
- Charcoal: primary text
- Stone/Slate: secondary UI
- Deep Forest: optional editorial dark section
- Brass/Gold: restrained premium accent
- Red/Amber/Blue: functional statuses only

## Typography
Existing app uses Inter globally. Keep UI readability.

Add an editorial display family only where it strengthens identity:
- hero
- major property titles
- section headings

Never use display typography for:
- tables
- forms
- data dense UI
- navigation
- CRM labels

## Shape
Prefer:
- medium/large radius
- thin borders
- soft shadow
- generous whitespace

Avoid:
- giant pills everywhere
- heavy neumorphism
- excessive glassmorphism

## Photography
Property photography is the hero asset.

Use:
- large aspect-ratio-safe media
- controlled overlays
- subtle image motion
- readable text over image
- consistent crop behavior

Do not let badges or controls cover the property focal point.
